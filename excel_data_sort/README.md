# 엑셀 데이터 정렬

업무용 Excel 양식을 최초 한 번 설정하고, 이후 같은 양식이나 헤더 위치·컬럼 순서가 달라진 유사 양식에서 분석용 정형 테이블(Dataset)을 추출하는 Rule 기반 프로젝트입니다. 원본 파일은 수정하지 않습니다.

## 실행 및 사용 순서

저장소 루트에서 `pip install -r requirements.txt` 후 `python main.py`를 실행하고 **문서 분석 > 엑셀 데이터 정렬**을 선택합니다. XLSX는 openpyxl, XLS는 xlrd로 읽으며 Microsoft Excel 설치 없이 변환할 수 있습니다.

1. 왼쪽의 **파일 추가**로 `.xlsx`, `.xls` 파일을 여러 개 선택하거나 **업로드 파일** 목록에 드래그 앤 드롭합니다. 중복 파일은 다시 추가하지 않으며, 드롭한 항목 중 지원하지 않는 파일·폴더·웹 주소는 무시합니다. 파일은 로컬에서 처리됩니다.
2. 저장된 양식이 있으면 파일별로 자동 인식합니다. 자동 인식에 실패하거나 후보가 비슷하면 등록된 양식을 선택하고 **현재 파일에 적용**을 누릅니다. 같은 양식을 모두 사용할 때는 **선택 양식 일괄 적용**을 사용합니다.
3. 새 양식이면 **새 양식**을 누르고 이름과 기준 시트, 헤더행, 데이터 시작행을 지정합니다. **원본 미리보기**로 행·열 위치를 확인합니다.
4. 가로로 나란한 테이블이 있으면 **기준 테이블 첫 열 / 끝 열**에 테이블 하나의 범위를 입력합니다. A열은 1, B열은 2입니다. 예를 들어 A:B와 D:E에 같은 테이블이 있으면 1~2로 설정합니다.
5. **헤더에서 컬럼 불러오기** 후 사용할 컬럼을 체크하고 출력 컬럼명을 지정합니다. 헤더행·기준 열 범위·병합 방식·숨김 열 옵션을 바꾸었다면 컬럼을 다시 불러옵니다.
6. 병합값 처리, 숨김 항목 포함, 반복 테이블·시트 병합, 빈 행과 합계행의 종료 조건을 설정합니다.
7. 설정 변경 시 자동 갱신되는 하단 **Dataset 결과**를 확인하고 상단의 **양식 JSON 저장**을 누릅니다. 설정은 `data/excel_templates/<양식명>.json`에 저장됩니다. 양식명이 같으면 덮어쓰기 확인을 표시합니다. 입력 중 유효하지 않은 설정은 Dataset 안내와 처리 내역에 표시하며, 수정하면 다시 자동 갱신됩니다.
8. **전체 파일 → Excel 저장**으로 모든 파일을 변환합니다. 양식을 선택하지 않았거나 데이터 추출에 실패한 파일이 있으면 전체 저장을 중단하고 해당 파일을 알려줍니다.

원본·Dataset 미리보기는 최대 500행·200열을 표시합니다. 출력에는 전체 결과를 저장합니다. 정규화는 변환 내부에서 수행하며 별도 Normalize 버튼·결과 탭은 제공하지 않습니다. 제외된 시트와 수식 처리 안내는 **처리 내역**에서 확인합니다.

## 설정과 Normalize 규칙

### 컬럼 추가

**양식 편집 / 설정**, **원본 미리보기** 옆의 **컬럼 추가** 탭에서 출력 컬럼을 추가합니다. 먼저 양식 편집에서 헤더 컬럼을 불러오세요.

1. Excel 형태의 배치 미리보기에서 열 또는 열 헤더를 선택하고 **선택 열 앞에 추가** 또는 **선택 열 뒤에 추가**를 누릅니다. A열 앞에 ‘연월’을 넣거나 B열 뒤에 새 컬럼을 넣을 수 있습니다.
2. 아래 설정 표에서 **컬럼명**과 **출력 위치**를 편집합니다. 위치는 사용할 원본 컬럼과 추가 컬럼을 합친 최종 출력 순서(A=1)이며 출처 표시 컬럼은 마지막에 붙습니다. 위치·컬럼명이 중복되면 안내를 표시합니다.
3. **고정값** 방식은 입력한 텍스트를 모든 데이터 행에 넣습니다. **원본 셀 값** 방식은 `B2` 같은 원본 셀 주소의 값을 각 파일에서 읽습니다. 참조 시트명을 비우면 현재 처리 중인 시트, 입력하면 해당 파일의 지정 시트를 사용합니다. 병합 영역은 왼쪽 위 대표값을 읽고 빈 셀은 빈값을 넣습니다. 없는 시트는 오류로 안내합니다.
4. 배치 미리보기는 원본 데이터 시작행부터 최대 20행을 보여줍니다. 아래 **Dataset 결과**에서 필터와 반복 테이블 처리를 포함한 실제 Dataset을 자동으로 확인합니다. **선택한 추가 컬럼 삭제**는 아래 설정 표에서 선택한 추가 컬럼을 삭제합니다.
5. **양식 JSON 저장**으로 추가 컬럼 설정도 저장합니다. 파일 전환, 양식 적용, 일괄 변환, CLI 및 Excel 저장에 같은 설정이 적용됩니다. 원본 파일과 원본 미리보기에는 컬럼을 삽입하지 않습니다.

### 추출 설정

추가 컬럼의 **매핑 설정**은 지점 관리 데이터를 조회하는 VLOOKUP 방식입니다. 값 방식을 **원본 셀 값**으로 설정하고 참조 셀을 지정한 뒤 **인식값**을 확인합니다. 매핑 창에서 **조회할 필드**(예: 기관기호)와 **가져올 필드**(예: 법인명)를 선택하면 인식된 지점과 가져올 값을 확인할 수 있습니다. 저장하면 **변경 후 값**과 미리보기에 반영됩니다. 마지막으로 **양식 JSON 저장**을 눌러 조회 설정을 보관하세요. 컬럼명과 가져올 필드는 자유롭게 지정할 수 있습니다.

조회 대상은 지점 관리의 기본 필드와 사용자 추가 텍스트 필드입니다. 이미지 필드는 제외합니다. 비교할 때 앞뒤 공백과 숫자형 정수의 소수점 표기만 정리하며, 문자형 `00100`과 `100`은 구분합니다. 빈 인식값, 일치하는 지점 없음, 여러 지점 중복, 삭제된 필드는 오류로 안내합니다. 반환 필드가 비어 있으면 빈값을 출력합니다. 변환할 때 최신 `data/branches.json`과 `data/branch_fields.json`을 읽으므로 지점 관리의 변경 내용이 반영됩니다. 비활성 지점도 조회 대상입니다. 조회 설정 해제 시 인식값을 그대로 출력합니다. 이전 버전의 직접 치환 양식은 호환되며 새 조회 설정 저장 시 직접 치환 설정을 대체합니다.

| 설정 | 동작 |
| --- | --- |
| 헤더행 | 기준 파일의 원본 행 번호. 데이터 추출 시 헤더 텍스트를 찾아 위치 변경에 대응 |
| 데이터 시작행 | 원본 행 번호. 반복·이동된 테이블에도 `시작행 - 헤더행` 간격 적용 |
| 데이터 끝행 | 0이면 값이 있는 마지막 행까지 자동 인식. 지정하면 `끝행 - 헤더행` 간격으로 각 테이블 범위 제한 |
| 기준 테이블 첫 열 / 끝 열 | 컬럼 설정을 불러올 원본 범위. 끝 열 0이면 마지막 열까지 |
| 병합 영역에 대표값 채우기 | 병합 해제 시 왼쪽 위 값을 병합 범위 전체에 복제 |
| 왼쪽 위 값만 유지 | 병합 해제 시 대표 셀만 값을 유지하고 나머지는 빈칸 |
| 숨김 행·열·시트 | 각각 포함 여부 선택. 기본값은 제외 |
| 등록된 모든 헤더 일치 | 출력에서 제외한 컬럼까지 포함해 등록된 헤더가 있어야 같은 테이블로 판단 |
| 사용할 컬럼의 헤더만 일치 | 체크한 컬럼의 헤더만 요구. 선택하지 않은 컬럼이 추가·삭제된 양식에 사용 |
| 빈 행에서 테이블 종료 | 기본값 꺼짐. 중간 빈 행을 건너뛰고 뒤의 데이터도 계속 추출. 켜면 첫 빈 행에서 종료 |
| 종료 값 | 기본 없음. 필요 시 `합계, 소계, 총계` 등을 입력. 일치한 테이블의 컬럼 중 완전히 같은 값이 나오면 해당 행부터 다음 헤더 전까지 제외 |
| 원본 정보 포함 | `_원본파일`, `_원본시트`, `_원본행`, `_테이블` 컬럼으로 추출 출처 기록 |

Normalize는 **병합 해제 → 빈 행 제거 → 빈 열 제거 → 숨김 옵션 적용** 순서입니다. 처리 전 원본 좌표와 빈 행 위치를 보존하므로 행·열 제거 후에도 설정과 출처 번호가 바뀌지 않습니다. 값 `0`과 `False`는 빈칸으로 취급하지 않습니다.

Normalize 후에는 **반복 헤더 위치 탐색 → 데이터 범위 추출 → 선택 컬럼 추출 → 컬럼명 변경 → 테이블·시트·파일 결과 결합**을 수행합니다. 빈 행에서 종료하도록 설정해도 다음에 같은 헤더가 등장하면 새 테이블로 처리합니다. 숨김 행을 제외한 것은 빈 행 종료로 취급하지 않습니다.

## 테이블·시트·파일 결합

- **테이블 합치기**: 같은 헤더를 가진 세로·가로 반복 테이블을 행 방향으로 연결합니다. `테이블별 분리`, `첫 테이블만`도 선택할 수 있습니다.
- **시트 합치기**: 헤더가 일치하는 시트를 모두 연결하거나 각각 분리합니다. `기준 시트명만 사용`은 이름이 정확히 일치하는 시트에 한정합니다.
- **여러 파일**: 양식명·Dataset명·출력 컬럼이 같은 결과를 하나로 연결합니다. 테이블 또는 시트 분리 옵션을 선택하면 파일 간에도 결과를 분리합니다.
- 출력명이 Excel 시트 이름 제한에 걸리면 사용 불가 문자를 바꾸고 길이를 줄이며 중복 번호를 붙입니다.

결합은 행을 추가하는 방식이며 관계형 조인이나 중복행 삭제를 수행하지 않습니다. 선택한 컬럼의 순서대로 출력하고, 입력 컬럼 순서가 바뀌어도 헤더 이름으로 대응시킵니다. 동일 이름의 헤더가 여러 개라면 왼쪽부터 등장 순서로 대응하므로 의미가 다른 동명 컬럼의 위치 변경은 미리보기에서 확인해야 합니다.

## 양식 자동 인식

양식 저장 시 헤더명, 컬럼 수, 병합 범위, 시트 이름·개수를 JSON의 `signature`에 기록합니다.

| 비교 항목 | 가중치 |
| --- | --- |
| 설정한 헤더명의 일치도 | 65% |
| 매칭된 헤더 범위의 컬럼 수 | 15% |
| 원본 병합 위치 | 10% |
| 시트 이름 및 개수 | 10% |

헤더의 공백과 영문 대소문자는 무시합니다. 종합 점수 80% 이상이고 실제 추출 가능한 헤더 구조가 있으며, 차순위와 점수 차이가 6%p 이상일 때 자동 선택합니다. 나머지는 수동 선택을 요구합니다. 수동 선택 후에도 헤더가 실제로 일치해야 데이터가 추출됩니다. 헤더 문구가 달라졌다면 실제 파일에서 컬럼을 다시 읽고 새 양식으로 저장합니다.

`1(토)`, `1(수)`처럼 1~31일과 한글 요일로 구성된 날짜 헤더는 요일을 제외하고 비교합니다. 날짜 숫자와 중복 개수는 그대로 검사하며 일반 헤더의 괄호 내용은 무시하지 않습니다. 자동 인식과 실제 추출에 같은 규칙을 적용합니다.

**처리 내역**에는 후보 양식별 종합 점수와 80% 기준, 헤더 일치 개수, 열·병합·시트 구성 점수, 헤더 후보 원본 행 번호, 누락·불일치 헤더, 추출 가능 여부가 기록됩니다. 실패 시 점수 미달·헤더 구조 불일치·상위 후보 점수 차이 미달을 구분합니다. **자동 인식 다시**로도 같은 상세 내역을 확인할 수 있습니다.

## CLI

앱에서 저장한 양식을 동일한 여러 파일에 적용할 수 있습니다. 실행 위치는 저장소 루트입니다.

```powershell
python -m excel_data_sort "입력1.xlsx" "입력2.xls" --template "data/excel_templates/노인급여.json" --output "Dataset.xlsx"
```

CLI는 기존 출력 파일을 덮어쓰지 않습니다. UI에서는 저장 대화상자에서 덮어쓰기를 확인합니다. 어느 실행 방식에서도 입력 원본과 같은 경로에 출력할 수 없습니다.

## 현재 범위

- 하나의 헤더행을 기준으로 규칙을 설정합니다. 여러 줄 헤더를 의미에 따라 합치는 기능과 AI 자동 학습은 아직 구현하지 않았습니다.
- 표 아래 설명이나 합계 문구를 자동으로 이해하지는 않습니다. 양식에 맞게 끝행·빈 행 종료·종료 값을 지정합니다. 종료 값은 부분 문자열이 아닌 전체 값으로 비교합니다.
- 셀 값과 날짜·숫자 등의 자료형을 출력합니다. 원본 글꼴, 색, 숫자 표시 서식, 병합 구조를 복제하지 않습니다.
- 수식은 실행하거나 계산하지 않고 Excel에 마지막으로 저장된 계산값을 사용합니다. XLSX에서 계산값이 없는 수식은 빈칸일 수 있으므로 원본을 Excel에서 재계산·저장한 후 불러옵니다. 수식처럼 보이는 문자열은 출력에서도 문자열로 보존합니다.
- 암호화 파일, XLSM·XLSB·CSV 입력은 지원 대상에 포함되지 않습니다.
- 시트 읽기 범위가 200만 셀을 넘으면 오류를 표시합니다. 사용하지 않는 마지막 행·열의 서식 때문에 범위가 커진 파일은 Excel에서 해당 범위를 삭제해 주세요. XLSX 출력 행·열 한도를 넘겨도 데이터를 자르지 않고 오류를 표시합니다.
- 저장한 JSON은 설정 파일이므로 Git 관리 대상입니다. 생성 XLSX에 대한 별도 Git 제외 정책은 추가하지 않았습니다.

## 구조 및 AI 확장 지점

| 파일 | 역할 |
| --- | --- |
| `models.py` | 공통 데이터 구조, 설정 검증, 버전이 있는 JSON 저장소 |
| `readers.py` | XLSX·XLS 입력을 같은 `WorkbookData`로 변환 |
| `normalize.py` | 원본과 분리된 정규화 및 좌표 보존 |
| `recognition.py` | `Recognizer` 인터페이스와 현재 `RuleRecognizer` |
| `engine.py` | `TableDetector` 인터페이스, 반복 헤더 탐색, Dataset 추출·일괄 변환 |
| `exporter.py` | XLSX 출력, 원본 덮어쓰기 방지, 임시 파일을 통한 저장 |
| `__main__.py` | UI 없이 저장된 양식으로 실행하는 CLI |
| `../ui/pages/excel_data_sort_page.py` | 양식 편집, 미리보기, 작업 스레드, 파일별 양식 선택 |

향후 AI 양식 인식은 `Recognizer.recognize(workbook, templates)`를 구현하고, 헤더·테이블 위치 분석은 `TableDetector.locate(normalized_sheet, template)`를 구현해 교체할 수 있습니다. `convert`와 `convert_many`는 detector를 주입받습니다. 원본 병합 위치와 숨김 정보는 `WorkbookData`에, 정규화 후 원본 좌표는 `NormalizedSheet`에 남아 있습니다. 학습 데이터 수집과 모델 학습·추론 자체는 별도 확장 작업입니다.

프로젝트 추가·기능 변경 시 이 문서와 [루트 README](../README.md)의 프로젝트 구성·사용 안내·저장 경로를 함께 갱신합니다.
