# MyTool

요양기관의 지점 정보, 로그인, 문서 작성 및 반복 업무를 한곳에서 처리하기 위한 Windows 데스크톱 도구입니다.

현재 구현 기준: 2026-09-09. PySide6 기반 업무 화면, 출근부 분석 모델, 엑셀 데이터 정렬 프로젝트를 포함합니다.

## 프로젝트 구성

| 프로젝트 | 위치 / 실행 | 주요 기능 |
| --- | --- | --- |
| 요양원 업무툴 | `main.py`, `ui/pages/` / `python main.py` | 지점·로그인 관리, 문서 생성, 개인 업무, 정보 조회, 웹 자동화 |
| 출근부 분석 모델 | `attendance_analysis/` / 앱의 `문서 분석 > 출근부 분석` 또는 CLI | 이미지·정답 데이터 학습, 출근부 이미지 분석, XLSX 결과 저장. [상세 안내](attendance_analysis/README.md) |
| 엑셀 데이터 정렬 | `excel_data_sort/` / 앱의 `문서 분석 > 엑셀 데이터 정렬` 또는 `python -m excel_data_sort` | XLSX·XLS를 JSON 양식에 따라 정규화하고 정형 Dataset으로 변환. [상세 안내](excel_data_sort/README.md) |

## 실행 환경

- Windows
- Python 3.10 이상
- 한글 문서 자동화 기능 사용 시 한컴오피스 한글 설치 필요
- Word 문서의 PDF 변환 기능 사용 시 Microsoft Word 설치 필요
- 출근부 모델 학습·분석은 PyTorch를 사용하며, CUDA 사용 가능 시 GPU를, 그 외에는 CPU를 사용합니다.
- 엑셀 데이터 정렬은 XLSX에 `openpyxl`, XLS에 `xlrd`를 사용합니다. 이 기능에는 Microsoft Excel 설치가 필요하지 않습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

프로젝트의 텍스트 파일과 JSON 데이터는 UTF-8을 사용합니다.

## 메뉴 구성

### 필수도구

- 로그인툴: 지점별 공단·케어포 로그인 실행

### 문서작성툴

- 문서작성툴(한글): `document_hwp` 폴더의 HWP 양식 설정 및 PDF 생성
- 문서작성툴(워드): `document` 폴더의 DOCX 양식 설정 및 PDF 생성
- 테이블 목록 관리: 문서 필드에서 선택할 공통 목록 관리

문서 목록에서는 다음 작업을 지원합니다.

- 설정: 누름틀 또는 콘텐츠 컨트롤별 입력 형태와 기본값 설정
- 생성: 입력값을 적용해 `maked` 하위 폴더에 PDF 생성
- 엑셀다운: 일괄 생성용 XLSX 양식 저장
- 엑셀업로드: XLSX 각 행을 이용한 문서 일괄 생성

문서 생성 편의 기능:

- 최근 작성 3건: 문서별 최근 제목, 지점 선택, 입력값을 불러와 재사용
- 필드 프리셋: 입력값 묶음 추가·복사·삭제, 적용할 필드 열 제외·복원, 생성 화면에서 `빈칸 채우기` 또는 `전체 적용`
- 엑셀 양식: 첫 열에 지점 선택, 필드명과 입력 형태가 포함된 헤더, 기본값 예시 행, 지점·테이블 목록·체크값 드롭다운 제공
- 지점의 값, 폴더 이미지, 다른 필드를 기준으로 계산하는 날짜·숫자는 엑셀 입력 열에서 제외하고 생성 시 계산
- 문서 생성 진행 상태 표시 및 동일한 PDF 파일명에 대한 중복 처리

엑셀 양식의 둘째 행은 기본값 예시이므로 실제 생성할 값으로 수정하거나 삭제한 뒤 업로드합니다. 문서 필드 설정이 바뀌면 `엑셀다운`으로 새 양식을 받습니다.

### 문서 분석

- 출근부 분석: 학습 데이터 수와 이미지·정답 쌍 확인, 학습 횟수 지정, 모델 학습, 이미지·모델 선택 및 XLSX 결과 저장
- `dataset/files/`의 이미지와 `dataset/labels/`의 같은 이름 XLSX 또는 JSON 정답을 짝지어 학습합니다.
- 분석에는 학습한 체크포인트가 필요하며 기본 경로는 `attendance_analysis/outputs/best.pt`입니다. 분석 품질은 학습 데이터와 모델에 따라 달라집니다.

저장소 루트에서 CLI로도 실행할 수 있습니다.

```powershell
python -m attendance_analysis.train --epochs 30
python -m attendance_analysis.predict dataset/files/attendance_001.jpg --checkpoint attendance_analysis/outputs/best.pt --output attendance_001_분석결과.xlsx
```

데이터 열 구성과 모델 교체 방법은 [출근부 분석 README](attendance_analysis/README.md)를 참고합니다.

엑셀 데이터 정렬:

- 여러 XLSX·XLS 파일을 불러오고 파일마다 저장된 양식을 자동 인식하거나 직접 선택합니다.
- 업로드 파일 목록에 XLSX·XLS 파일을 드래그 앤 드롭할 수 있습니다. ‘컬럼 추가’ 탭에서는 출력 열 사이에 고정값 또는 원본 셀 값을 담는 컬럼을 삽입하고 양식에 저장합니다.
- 추가 컬럼의 ‘매핑 설정’에서 지점 관리의 조회 필드와 가져올 필드를 선택합니다. 예를 들어 기관기호로 지점을 찾아 해당 지점의 법인명을 출력합니다. 조회 설정은 양식에 저장되며 미리보기와 Excel 출력에 적용됩니다.
- 헤더행·데이터 시작/끝행, 기준 테이블의 열 범위, 사용할 컬럼·출력 컬럼명, 병합값 처리, 숨김 행·열·시트, 테이블·시트 합치기 기준을 화면에서 설정합니다.
- 양식은 `data/excel_templates/<양식명>.json`에 저장합니다. 예: `노인급여.json`, `생계급여.json`, `출근부.json`.
- 원본을 수정하지 않고 병합 해제 → 빈 행 제거 → 빈 열 제거 → 숨김 옵션 적용 후 반복 헤더를 찾아 실제 데이터와 지정 컬럼을 추출합니다.
- 기본적으로 중간 빈 행을 건너뛰고 값이 있는 마지막 행까지 추출합니다. 컬럼 설정과 미리보기의 값은 가운데 정렬합니다.
- 가로·세로 반복 테이블과 같은 헤더를 가진 시트를 합치거나 따로 출력할 수 있습니다. 원본 미리보기와 설정 변경 시 자동 갱신되는 Dataset 결과를 제공합니다. 양식 저장 버튼은 상단에 있습니다.
- 날짜 헤더는 월별 요일 변경을 허용하며, 처리 내역에서 자동 인식 후보별 점수와 누락 헤더·실패 사유를 확인할 수 있습니다.
- `전체 파일 → Excel 저장`으로 XLSX를 저장합니다. 같은 양식과 출력 컬럼의 결과는 합치고, 다른 양식이나 분리 설정의 결과는 별도 시트로 저장합니다.
- 현재는 Rule 기반입니다. 헤더·컬럼 수·병합 위치·시트 구조로 인식하며, 낮은 점수나 유사 후보가 겹치면 수동 선택이 필요합니다. AI 분석은 향후 확장을 위한 인터페이스만 마련되어 있습니다.

상세 사용 순서, 종료 조건과 인식 범위는 [엑셀 데이터 정렬 README](excel_data_sort/README.md)를 참고합니다.

### 개인 업무

- 월간업무체크: 지점별 월간 업무 등록 및 완료 상태 확인
  - 업무 추가·이름 변경·삭제, 연월별 완료 처리·취소 및 완료 시각 표시
  - `월간 업무 총괄 확인`에서 지점별 업무 현황을 한눈에 확인하고, 업무별 `전체 완료`로 표시 대상 지점의 미완료 건을 일괄 처리
- 메모장: 메모 검색, 태그 지정 및 태그 관리
  - 태그마다 상징색을 지정할 수 있으며 메모 목록과 태그 선택 목록에 색상이 표시됩니다.
  - 태그 관리 목록에서 각 태그를 사용하는 메모 개수를 확인할 수 있습니다.
- 미비된일: 제목·내용으로 업무 추가, 더블클릭 수정, 검색·삭제 및 완료 처리
  - 기본 목록에는 미완료 업무를 표시하고, `완료된 업무`를 선택하면 완료 기록과 완료일을 확인합니다.

### 설정

- 지점 관리: 지점 정보, 로그인 정보 및 사용자 정의 항목 관리
- 업무별 지점 설정: 각 업무 화면에 표시할 지점을 체크박스로 선택

업무별 지점 설정은 `로그인툴`, `문서작성툴`, `월간업무체크`, `공단툴`, `케어포툴`에 적용됩니다.

- 업무별 설정이 한 번도 저장되지 않은 경우 기존처럼 모든 활성 지점을 표시합니다.
- 설정을 저장한 뒤에는 해당 업무에 체크된 활성 지점만 표시합니다.
- 지점 관리에서 비활성화된 지점은 업무별 체크 여부와 관계없이 표시하지 않습니다.
- 지점 식별에는 기관기호를 우선 사용하고, 기관기호가 없으면 지점명을 사용합니다.
- 한글과 Word 문서작성툴은 `문서작성툴` 설정을 함께 사용합니다.

### 테스트중

- 공단툴
- 공단툴은 `청구 명세서 만들기`, `장기근속수당 입력하기` 작업과 작업 추가·삭제 및 매크로 설정을 제공합니다. 청구 자동화에는 대상자 생성과 대상자별 명세서 자동 처리 흐름이 구현되어 있습니다.
- 작업을 선택하고 **매크로 복사**를 누르면 저장된 매크로 전체를 새 작업으로 복사합니다. 단계 순서·조건·반복·대기·브라우저 설정을 포함하며 복사본 수정은 원본에 영향을 주지 않습니다.
- **작업 삭제**는 팝업에서 작업을 선택하고 삭제 여부를 확인합니다. 취소하면 변경하지 않으며, 삭제 후에도 매크로 JSON 파일은 보관합니다.
- 작업 추가와 복사는 한글 작업명만 입력합니다. 파일명은 업무 용어를 영문으로 변환해 `federation_selectors_<영문명>.json`으로 자동 생성합니다. 사전에 없는 표현은 고유 식별자를 붙이고 같은 이름은 숫자를 덧붙여 기존 파일을 덮어쓰지 않습니다. 일반 문장 전체를 번역하는 기능은 아닙니다.
- **시작번호**는 기존 테스트 시작번호 위치에서 설정하며 작업별로 저장합니다. 전체 실행은 1이고 개별·다중 지점의 증가 반복에 동일하게 적용됩니다. 매크로 설정 안의 중복 입력칸은 제거했습니다.
- 시작 설정의 **범위 반복값**에서 `정수`, `연`, `연월`, `연월일`을 선택하고 시작·종료값, 정순/역순, 간격을 지정합니다. 연은 `2026`, 연월은 `2026-08`, 연월일은 `2026-08-31` 형식입니다. 연만 선택하면 연 단위, 연월이면 월 단위, 연월일이면 일 단위로 순회합니다. 월의 연도 전환과 윤년을 처리합니다. 간격에 도달하는 종료값까지 포함합니다. `기존 명단 번호`는 이전 증가 반복 동작을 유지합니다.
- 매크로 설정에서 반복지점 시작의 동작을 **값 범위 반복 (시작·종료값)**으로 선택하고 반복할 단계를 시작·종료 사이에 둡니다. 이 모드에서는 반복 횟수 셀렉터 대신 위의 범위를 사용합니다. 엘레멘트 동작 **값 입력 (검증)**의 보조값에 `{repeat_value}`를 입력하면 현재 반복값을 입력합니다. XPath가 입력칸의 부모 영역이면 내부의 표시된 입력칸 하나를 찾아 입력하며, 입력값 검증 실패 시 멈춥니다.
- **급여 다운로드**는 메뉴 진입 후 급여기준연월 입력부터 REXPERT 출력창의 다운로드·옵션수정·저장까지를 범위 반복으로 묶었습니다. 인쇄는 실제 포인터로 클릭하고 열람 사유 화면이 나타난 것을 확인한 뒤 진행합니다. 이미 선택된 출력 사유는 다시 펼치지 않으며, REXPERT 아이콘도 실제 포인터 클릭으로 처리합니다. 출력 확인 후에는 REXPERT 화면이 완전히 준비되도록 3초 기다린 뒤 다운로드 버튼을 누릅니다. 초기 범위는 `2026-08`부터 `2025-01`까지 월 단위 역순 20회입니다. 범위는 작업별로 저장되고 개별·다중 지점에서 같은 설정을 사용합니다. 로그의 `[range]`에 현재 연월이 표시됩니다. 실제 화면의 입력칸·팝업 복귀와 다운로드 완료 여부는 사이트에서 확인해야 하며, 실행 오류는 자동으로 건너뛰지 않습니다.
- **다중 지점 선택**은 월간업무체크처럼 지점 목록을 표시하는 팝업을 엽니다. 업무별로 사용 가능한 지점이 기본 모두 선택되며, 체크를 조정하고 **선택 지점 실행**을 눌러야 시작합니다. 표시된 순서로 로그인 → 매크로 완료 → 브라우저 종료 후 다음 지점을 실행합니다. 로그인·매크로 실패도 기록하고 브라우저 정리 후 다음 지점으로 진행합니다. 브라우저 종료 실패 시에는 다음 지점 실행을 중단합니다.
- **현재 지점 완료 후 중단**을 누르면 현재 지점을 마치고 브라우저를 닫은 뒤 멈춥니다. 실행 중 앱 닫기도 같은 중단 요청을 보내며 완료 후 다시 닫을 수 있습니다. 로그에 지점별 성공·실패와 미실행 개수를 표시합니다. 개별 실행 브라우저가 열려 있으면 닫은 뒤 다중 실행을 시작합니다.
- 작업 실행 영역의 **예상치 못한 팝업/얼렛/프롬프트를 닫고 계속 진행**은 작업별로 저장됩니다(기본 해제). 체크하면 요소 탐색 전에 브라우저 alert/confirm/prompt를 확인하고 취소·닫기로 처리한 뒤 탐색을 이어갑니다. 클릭을 가로막거나 탐색 시간이 초과되면 매크로 대상이 없는 표준 dialog 영역의 닫기·취소 버튼을 찾아 닫습니다. 로딩 중인 출력 화면을 보호하기 위해 추가 브라우저 창은 자동으로 닫지 않습니다. 명시적인 alert/confirm/prompt/window 단계와 작업 대상이 포함된 dialog는 유지합니다. 단계별 복구는 최대 3회입니다. `[popup_recovery]` 로그에는 대화상자 내용과 처리 방식이 기록됩니다. 확인을 눌러야 다음 화면으로 진행하는 대화상자는 명시적인 confirm/alert 수락 단계로 설정합니다. 사이트 전용 팝업이나 Windows 파일 선택창 등은 별도 설정이 필요할 수 있습니다.
- 조건부로 나타나는 alert/confirm/prompt는 매크로 설정에서 **확인/수락 (없으면 계속)** 또는 **취소/닫기 (없으면 계속)** 동작을 사용합니다. 지정한 대기시간 동안 대화상자가 나타나면 처리하고, 나타나지 않으면 오류 없이 다음 단계로 진행합니다. 급여 다운로드의 상세조회와 인쇄 사이에는 조회 결과 alert을 위한 조건부 닫기 단계가 기본 설정되어 있습니다.
- 클릭·값 입력 대상이 현재 위치에 없으면 약 1초 뒤부터 열린 다른 창과 중첩 프레임도 같은 대기 제한시간 안에서 탐색합니다. 20초를 모두 소진한 뒤 다시 20초 탐색하는 방식을 제거했습니다. 클릭 가능한 요소를 찾은 창·프레임으로 전환하며 `[target_context]` 로그에 탐색 결과를 남깁니다. 실패 시 대상 이름과 셀렉터를 포함한 오류를 표시합니다. 새 출력 창은 자동으로 닫지 않습니다. 급여 다운로드는 다음 연월 반복 전에 반복 시작 창의 기본 프레임으로 복귀하며 `[range_context]`에 기록합니다.
- 자동 팝업 복구 중 **조회된 대상자 내역이 없습니다.** 알림도 일반 방해 alert과 동일하게 닫고 현재 단계의 대상 탐색을 재개합니다. 다음 화면이 나타나면 현재 매크로와 이후 연월 반복을 계속하며, 대상 요소가 실제로 나타나지 않을 때만 해당 단계의 제한시간 후 오류로 처리합니다. 같은 창·프레임 탐색 결과는 연속해서 반복 출력하지 않습니다.
- 현재 프레임에서 대상을 먼저 확인하고, 출력 프레임이 갱신되면 작업별 `context_scan_interval` 간격으로 열린 창·프레임을 다시 탐색합니다. 급여 다운로드는 0.35초로 설정해 다운로드·저장 버튼 탐색 지연을 줄였습니다. 실패 후에는 최상위 화면이 아니라 원래 프레임으로 복귀합니다. 프레임 위치는 인덱스 대신 프레임 요소와 문서 일치 여부로 확인합니다. `tests/test_federation_browser.py`는 `MYTOOL_CHROMEDRIVER`에 설치된 ChromeDriver 경로를 지정하면 실제 headless Chrome과 로컬 HTML로 지연 로딩 중 불필요한 전환이 없는지 검증합니다. 공단 사이트에는 접속하지 않습니다.
- 케어포툴

테스트중 메뉴는 개발 중인 자동화 기능이므로 실제 업무 적용 전에 결과를 확인해야 합니다.

## 문서 필드 형태

한글은 누름틀 이름, Word는 콘텐츠 컨트롤의 태그를 필드 이름으로 사용합니다. 동일한 이름이 여러 번 나오면 같은 값을 함께 적용합니다.

지원 형태:

- 텍스트
- 날짜: 오늘 또는 다른 날짜 필드를 기준으로 일수 계산
- 숫자: 숫자 검증, 천 단위 쉼표 및 다른 필드값을 기준으로 사칙연산
- 분기: 같은 그룹의 필드 중 사용자가 선택한 하나만 입력
- 그룹: 관련된 여러 필드를 하나의 입력 영역에 묶어 표시
- 다중 체크: 체크 상태 입력 및 한글 양식 체크박스 연동
- 지점의 값: 선택한 지점의 기본 정보 또는 사용자 정의 항목 사용
- 테이블 목록: 테이블 목록 관리에서 등록한 값 선택
- 폴더의 이미지: 다른 필드값과 확장자를 제외한 파일명이 같은 이미지를 찾아 삽입하고 너비·높이를 mm 단위로 지정

## 분기 필드 정책

분기는 여러 누름틀이나 콘텐츠 컨트롤 중 하나만 선택해 값을 넣을 때 사용합니다.

필드 이름은 다음 형식을 사용합니다.

```text
분기_<그룹명>_<항목명>
```

예시:

```text
분기_변경전_대표자
분기_변경전_시설명칭
분기_변경전_시설소재지
```

위 필드는 `분기_변경전`이라는 하나의 그룹으로 자동 인식됩니다.

- 설정 화면에는 `분기_변경전` 아래에 묶인 항목과 각 항목의 입력 설정을 표시합니다.
- 분기 항목 셀렉트박스에는 `대표자`, `시설명칭`, `시설소재지`가 표시됩니다.
- 설정 화면에서 자식 항목별 입력 형태와 기본값을 저장합니다.
- 생성 화면에서는 그룹별 셀렉트 목록에서 이번 문서에 사용할 항목을 직접 선택합니다.
- 생성 화면에서는 선택한 항목에 저장된 입력 형태를 사용해 값을 입력합니다.
- 분기의 자식 형태로 다시 `분기`를 선택할 수는 없습니다.
- 문서 생성 시 선택한 누름틀 또는 콘텐츠 컨트롤만 수정하며, 같은 그룹의 선택하지 않은 필드는 변경하지 않습니다.
- 그룹명과 항목명은 비워둘 수 없습니다.
- 항목명에 밑줄이 포함된 경우 첫 두 구분자 뒤의 문자열 전체를 항목명으로 사용합니다.

그룹 필드는 `그룹_<그룹명>_<항목명>` 형식을 사용합니다. 예를 들어 `그룹_직원_성명`, `그룹_직원_생년월일`은 같은 영역에 함께 표시됩니다. 분기와 그룹은 이름에 적힌 순서대로 결합할 수 있습니다. 예를 들어 `분기_변경전_대표자_그룹_인적사항_성명`은 대표자 선택 시 표시할 그룹 필드이며, `그룹_직원_연락처_분기_종류_휴대폰`은 그룹 안에 분기 선택을 둡니다.

필드 이름이나 그룹·분기 구조를 변경한 양식은 설정 화면에서 각 항목을 확인하고 다시 저장합니다.
